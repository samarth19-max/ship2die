# 🚀 BF Rocket

**Enter your offer once. Publish it without the mistakes.**

BF Rocket is a solo-founder tool built for [Ship or Die's $100K hackathon](https://www.ship-or-die.com/100k-hackathon): you enter your promotion once — product, prices, checkout link, deadline with an explicit timezone — and it produces everything you need to publish it, consistently and without the classic launch mistakes.

## What it does

- **One offer, used everywhere** — the page's buy button points at your checkout link; the launch posts point at your public page URL. If your page URL isn't decided yet, posts ship **DRAFT-marked** with a placeholder instead of silently linking the wrong place.
- **Timezone-correct deadline** — you pick the UTC offset; every visitor sees the countdown end at the same instant.
- **Pre-flight review** — the tool checks what it can (sample/missing links, price math, deadline, campaign label) and hands you an explicit human checklist for what only you can verify: *"Open your checkout and confirm it actually charges $29."*
- **Campaign pack** — one download: `index.html` + `og.png` + `launch-copy.txt` + `publish-checklist.txt`.
- **Runs 100% in your browser** — no accounts, no backend; your data stays in local storage. The whole builder also ships as a single offline HTML file.

## Run it

No build step, no dependencies:

```bash
python3 -m http.server 8341
# open http://localhost:8341
```

Or just open `app/index.html` directly — it's a single file.

## Stack

One HTML file per page. Vanilla JS. The core is a `renderer(cfg)` function that emits standalone, dependency-free deal-page HTML; an OG banner painter on canvas; a hand-written stored-ZIP writer; and a pre-flight review engine that separates what a tool can verify from what only a human can.
